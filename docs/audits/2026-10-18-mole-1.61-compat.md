# Nora 1.3.1 — Mole 1.61.0 compatibility / Сумісність

Verified on Apple Silicon, macOS 27.0.1, Xcode 27.1, installed Mole 1.61.0. Compared the official [1.59.1…1.61.0 sources](https://github.com/tw93/Mole/compare/V1.59.1...V1.61.0) and [release](https://github.com/tw93/Mole/releases/tag/V1.61.0) against Nora's command arguments, environment variables and readers. Real removal tests use an isolated temporary home, never installed user applications or the real Trash.

Перевірено на Apple Silicon, macOS 27.0.1, Xcode 27.1 із Mole 1.61.0. Порівняно офіційні зміни 1.59.1…1.61.0 з командами, змінними середовища й читанням результатів у Nora. Реальні тести видалення виконуються в тимчасовому домашньому каталозі, не зачіпають установлені програми користувача чи справжній кошик.

## Confirmed fixes / Підтверджені виправлення

| Area / Ділянка | Result / Результат |
| --- | --- |
| Uninstall / Видалення | `uninstall_name` can be a Homebrew token (`vivid-app`), while Mole matches the application name (`Vivid`). Nora now uses the name and verifies the selected bundle path in the preview. / Nora використовує назву програми й перевіряє точний шлях до вибраної програми в перегляді. |
| Personal data / Особисті дані | Mole 1.61 adds `Personal data kept:`, `⊙`, `D choose personal data` and `[Brew]` groups. Nora reads the exact data menu, selects its validated paths for review, verifies the final union and cancels the dry run. Execution confirms only the exact reviewed list. / Nora читає нове меню, включає перевірені особисті дані до видимого списку та підтверджує лише точний погоджений набір. |
| Authentication / Права адміністратора | `source == "Homebrew"` requires authentication even if the bundle is writable. Command preview and execution share the same check. / Для Homebrew права адміністратора можуть бути потрібні навіть за доступного на запис файла програми; показ команди й виконання використовують спільну перевірку. |
| Running apps / Відкриті програми | Consent names only selected, reviewed open apps. Normal Quit allows saving; refusal, newly opened apps a final Mole `[Running]` state, or a fresh macOS running-app check immediately before Enter block removal. Стан кошика перевіряється до завершення програм. |
| History / Історія | `*-dry-run` sessions contain prospective sizes (the probe recorded 1.06 GB). They remain visible but are excluded from freed-space, action and chart totals. / Записи попереднього перегляду залишаються видимими, але не збільшують звільнене місце, кількість виконаних дій чи графік. |

| Maintenance / Обслуговування | Recognizes the exact `Disk verify skipped` message; tasks remain read dynamically, including upstream task removals. / Перекладено нове повідомлення про пропуск перевірки диска; список доступних завдань читається динамічно. |

## Evidence / Докази

- Isolated-home MoleKit run: 84 Swift Testing tests passed; 63 XCTest tests, zero failures, two explicit skips (the filesystem rejects non-UTF-8 names; optional real capture directory unset). Uninstall covers exact deletion of the fixture app and its data, a non-destructive preview, and refusal of an unexpected path. Installer, project and whitelist end-to-end checks also passed. The final targeted run passed all 11 uninstall parser/isolated-home tests, including `[Running]` and a fresh running-state check after the scan; the installer-pin tests passed separately.
- Ізольований запуск MoleKit: 84 тести Swift Testing успішні; 63 тести XCTest без помилок, два явні пропуски (неможливо створити ім'я не у UTF-8; не задано необов'язкову папку записаних результатів). Перевірено видалення лише тестової програми та її даних, перегляд без видалення й відмову за зайвого шляху; також пройшли наскрізні перевірки інсталяторів, проєктів і захищених шляхів. Остаточний цільовий запуск11 перевірок читання й ізольованого видалення успішний, включно з[Running] та свіжим станом програми після сканування; перевірки версії інсталятора пройшли окремо.
- Read-only probes: `clean --dry-run` produced a complete accepted plan; `optimize --dry-run` produced nine accepted tasks; `analyze --json` and `history --json` decoded; `touchid status` and `remove --dry-run` exited successfully. Live `status --watch` decoded CPU, memory and three disks. Live VLC uninstall preview read seven paths and exited after ESC without removal.
- Безпечні перевірки: прийнято повний план очищення, дев'ять завдань обслуговування та дані аналізу й історії; перевірки Touch ID і перегляду видалення Mole завершилися успішно. Живий стан системи прочитано для процесора, пам'яті й трьох дисків. Перегляд VLC прочитав сім шляхів і завершився ESC без видалення.
- Targeted Nora checks: 51 compatibility/application/history/Trash tests, 17 prompt/removal/Trash-integration tests and 28 final app/quit/Trash tests passed. Rendered English, Ukrainian and Russian snapshots cover the All apps entry and one/five-app quit prompts; no product action is pressed by snapshot tests. All 884 current Debug localization keys match the catalog with no translation errors.
- Цільові перевірки Nora: 51 тест сумісності, програм, історії та кошика, потім17 тестів запиту, видалення й взаємодії з кошиком та28 остаточних перевірок програм, завершення й кошика — без помилок. Знімки трьома мовами охоплюють «Всі програми» та запит із однією/п'ятьма програмами. Під час знімків жодна дія програми не запускається. Усі 884 ключі перекладу поточного складання Debug відповідають каталогу, помилок перекладу немає.

## Boundaries / Межі перевірки

Unknown, wrapped, truncated, duplicate or changed removal plans fail closed. The personal-data menu must fit fully on screen (Mole currently limits it to 50 visible rows); larger menus are refused rather than confirmed without inspecting hidden paths. Same-name app matches must resolve to the reviewed bundle path. Nora does not claim support for every future Mole release merely because its version is accepted.

Невідомі, перенесені, обрізані, дубльовані чи змінені плани зупиняють видалення. Меню особистих даних має бути видимим повністю: Mole зараз показує до 50 рядків; більший список відхиляється, щоб не підтверджувати приховані шляхи. За однакових назв програми шлях має відповідати вибраному. Прийняття номера версії не доводить сумісність із майбутніми випусками Mole.

The final running check narrows the race window; macOS does not atomically lock app launches together with Mole removal. / Остаточна перевірка звужує проміжок одночасних подій; macOS не блокує запуск програми атомарно разом із видаленням Mole.

Not exercised: deletion of real installed apps, actual administrator authentication/Homebrew uninstall, real unsaved-document dialogs, real Trash deletion, Intel or macOS 14 execution, and a fresh official installer run. Security and Nora's own Trash use independent implementations; no changed Mole command contract was found there. Existing Cleanup/Projects rescan limits documented in the 1.3.0 audit still apply.

Не виконувалися: видалення справжніх установлених програм, реальне отримання прав адміністратора й видалення через Homebrew, справжні діалоги збереження документів, очищення справжнього кошика, запуск на Intel чи macOS 14 та повторне встановлення Mole. Безпека й власний кошик Nora мають окремі реалізації; змінених залежностей від команд Mole там не виявлено. Раніше описані межі повторного сканування очищення та проєктів залишаються чинними.
