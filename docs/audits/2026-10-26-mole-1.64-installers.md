# Mole 1.64 installer compatibility / Сумісність інсталяторів Mole 1.64

## Source / Джерела

- Installed Homebrew executable: Mole 1.64.0, Apple Silicon. Official release: <https://github.com/tw93/Mole/releases/tag/V1.64.0>, published 2026-10-25.
- Встановлений через Homebrew Mole має версію 1.64.0; перевірка виконана на Apple Silicon. Офіційний випуск опубліковано 25 жовтня 2026 року за посиланням вище.
- `install.sh` at `V1.64.0`: 70,695 bytes; official raw and Contents API downloads are identical. SHA-256: `f60bed00d120f758190998dd25083cdc834dd968e1ff24e525dee287f5b12137`.
- Офіційні способи отримання `install.sh` повернули однакові 70 695 байтів із наведеною контрольною сумою; версію й контрольну суму закріплено в `MoleSetup`.

## Findings and changes / Висновки та зміни

- Mole's installer menu still shows name, size and source, and the confirmation shows full basenames. `MOLE_DELETE_MODE=trash` remains supported. The final filesystem operation revalidates the confirmed file identity.
- Меню інсталяторів і далі показує назву, розмір та джерело, а підтвердження — повні назви файлів. Режим `MOLE_DELETE_MODE=trash` підтримується; перед операцією Mole повторно перевіряє ідентичність файлу.
- Nora's `name|source` row IDs collided for files in different subfolders sharing the same source label. A ten-row native fixture reproduced the screenshot: two rows vanished, leaving a blank gap; toggling one same-named row affected every copy. Each scan entry now has a stored UUID, stable throughout that snapshot.
- Спільний номер `name|source` спричиняв конфлікти між однойменними файлами в різних підтеках одного джерела. Відтворення з десятьма записами показало зникнення двох рядків і порожній проміжок; одна позначка діяла на всі копії. Кожен запис тепер має власний збережений UUID на весь час показу результатів сканування.
- Confirmation matches individual review rows, allowing identical basenames only in the required multiplicity. Unexpected files, changed counts, distinct full names matching an ambiguous truncated prefix, and ambiguous menu identities still refuse confirmation.
- Підтвердження звіряє окремі рядки й дозволяє лише потрібну кількість повторних назв. Зайві файли, інша кількість, різні повні назви під одним неоднозначним обрізаним префіксом та неоднозначні рядки меню й далі зупиняють підтвердження.
- Mole 1.64's successful empty message, `Great! No installer files to clean`, is recognized; a nonzero exit or the dry-run banner alone is still not an empty success.
- Розпізнається успішне повідомлення Mole 1.64 без знайдених інсталяторів; ненульовий код завершення або лише повідомлення про режим попереднього перегляду не вважаються успіхом.
- Mole 1.64 removes the preliminary app-match confirmation, renders personal-data menu controls on one line when they fit, and adds a `Personal data to remove:` heading after data selection. Nora supports these contracts and the older flow. It validates the matched app before sending any response, sends `y` only to the legacy match prompt, and includes selected personal paths in the exact final file plan.
- Mole 1.64 прибрав початкове підтвердження вибору програми, розміщує підказки меню даних в одному рядку, якщо вони вміщаються, та додав заголовок вибраних особистих даних. Nora підтримує новий і старий порядок: перевіряє назву програми до відповіді, надсилає `y` лише на старе початкове запитання та звіряє вибрані особисті шляхи як частину остаточного списку файлів.
- Mole 1.64 intentionally protects project dependencies without evidence they can be restored. The purge fixture now provides both a lockfile and an installation record, rather than weakening the production guard.
- Mole 1.64 навмисно зберігає залежності проєкту, якщо немає доказів можливості їх відновлення. Тестовий приклад тепер містить файл фіксації версій і запис встановлення; захисна поведінка не послаблюється.

## Evidence / Докази

- Before/after native PNGs: `build/installers-ui-before.png`, `build/installers-ui-after.png`. Before: duplicate-ID warnings and four independent-selection assertion failures. After: all ten rows are contiguous, no duplicate-ID warning, seven targeted application checks passed.
- Знімки до та після наведено вище. До виправлення були попередження про повторні номери та чотири помилки перевірки незалежного вибору. Після — усі десять рядків показано поспіль, попереджень немає; сім цільових перевірок програми пройшли.
- `build/mole164-targeted.log`: eight targeted checks passed, including real Mole 1.64 deleting exactly two of three same-named synthetic copies while preserving the third and five unrelated fixtures, plus a separate move to a sandbox Trash. `MOLE_TEST_NO_AUTH=1` enables Mole's test Trash override; `MOLE_TEST_MODE=1` suppresses the installer entry point and is unsuitable for CLI end-to-end runs.
- Вісім цільових перевірок пройшли: справжній Mole 1.64 видалив лише дві з трьох штучних однойменних копій, зберіг третю й п'ять інших тестових файлів; окремо перевірено переміщення в ізольований кошик. Для такого кошика потрібен `MOLE_TEST_NO_AUTH=1`; `MOLE_TEST_MODE=1` вимикає запуск команди й для наскрізної перевірки не підходить.
- Full release-gate output, final signing, notarization and artifact hashes are recorded in `build/release-1.3.3.log` when the release is built. Release tests can use `NORA_TEST_DERIVED_DATA` to avoid rebuilding the user's running debug app.
- Повна перевірка випуску, підписи, перевірка Apple та контрольні суми записуються в наведений журнал під час складання. Окремий каталог `NORA_TEST_DERIVED_DATA` дозволяє не перезаписувати запущену налагоджувальну копію користувача.
- Independent external review did not return a verdict: one advisor hit its quota, another returned no conclusion, and a third timed out. It is not counted as a passed gate.
- Незалежний зовнішній перегляд не дав висновку: один сервіс вичерпав ліміт, інший не повернув висновку, третій перевищив час очікування. Він не зарахований як успішна перевірка.

## Limits / Межі

- No real user installer or home Trash was removed. Actual administrator authentication, deletion of real apps, Intel runtime and the official install script's execution are not asserted by these fixtures. Universal binary, Gatekeeper and public-byte release checks are separate gates.
- Справжні інсталятори й кошик користувача не очищалися. Ці перевірки не доводять реальне отримання прав адміністратора, видалення встановлених програм, запуск на Intel чи виконання офіційного інсталятора. Універсальне складання, Gatekeeper і відповідність публічного пакета перевіряються окремо.
