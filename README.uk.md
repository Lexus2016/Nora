## Навіщо Nora

[Mole](https://github.com/tw93/Mole) — чудовий відкритий набір інструментів командного рядка, що поєднує можливості CleanMyMac, AppCleaner, DaisyDisk та iStat Menus. Nora дає йому спокійне, нативне й гарне обличчя і нічого не приховує.

- **Спершу перегляд, потім видалення.** Кожен модуль працює однаково: *Сканувати → Переглянути → Готово*. Ви бачите кожен шлях і розмір ще до того, як Mole щось зробить.
- **Чесні чекбокси.** Чекбокс з'являється лише тоді, коли Nora може змусити Mole його виконати. Зняті позиції захищає тимчасовий whitelist Mole, який Nora потім повертає. На запити в інтерактивних меню Mole Nora відповідає лише після звірки списку на екрані з вашим вибором. Жодних декоративних галочок.
- **Нічого не сховано.** Кожна дія показує точну команду `mo …`, а вбудована консоль показує живий вивід Mole.
- **Сама встановлює й оновлює Mole.** Один клік і без Термінала: через Homebrew, якщо він є; інакше — офіційний інсталятор Mole закріпленої версії з перевіркою контрольної суми, у `~/.local/bin` і без пароля адміністратора. Nora й сама оновлюється (Sparkle 2, підписаний канал).
- **Меню швидкого доступу в меню-барі.** Живі здоров'я системи, CPU, пам'ять, мережа, диск, графіка, вентилятор, батарея, топ-процеси й місце, яке можна звільнити. Звідти ж — перехід у будь-який розділ в один клік.
- **Нативна й легка.** SwiftUI + AppKit. Nora керує Mole, який уже встановлено, без власного «рушія».
- **Ваша мова — автоматично.** Англійська, українська або російська, залежно від мови macOS. Для інших мов — англійська.

## Можливості

| Модуль | Що робить | Під капотом |
|---|---|---|
| **Розумний догляд** | Одна перевірка без видалення: кеші, артефакти проєктів, інсталятори, великі файли; потім один безпечний *Запуск* | `mo clean --dry-run`, `mo purge --dry-run`, `mo installer --dry-run`, `mo analyze --json` |
| **Очищення** | Кеші, журнали, залишки видалених програм, Кошик; за бажанням системні кеші (Touch ID або пароль) | `mo clean` + whitelist-оверлей, `sudo -A` у тій самій PTY-сесії |
| **Програми** | Видалення разом із LaunchAgents, кешами й налаштуваннями; особисті дані лишаються; у Кошик або остаточно | `mo uninstall --list` (JSON), `mo uninstall [--permanent] "Програма"` |
| **Швидкодія** | 20 задач обслуговування (DNS, Spotlight, кеш Finder, бази даних, мережа…), кожну можна вимкнути | `mo optimize`, `~/.config/mole/whitelist_optimize` |
| **Аналіз диска** | Кільця і плитки, перехід углиб, інсайти (старі завантаження, резервні копії iOS, дані Xcode/Docker), великі файли, зовнішні диски | `mo analyze --json PATH` |
| **Стан системи** | Здоров'я, CPU по ядрах, тиск пам'яті, I/O диска, мережа, батарея, температури, Bluetooth, процеси, CPU-алерти | `mo status --watch --interval 1s` (NDJSON) |
| **Проєкти** | `node_modules`, `target`, `build`, `.venv`… за проєктами; нещодавно активні не чіпаються | `mo purge [--yes]` |
| **Інсталятори** | Забуті DMG / PKG / ISO / XIP / ZIP у Завантаженнях, iCloud, Пошті, Telegram, Homebrew | `mo installer` |
| **Історія** | Панель активності: звільнене місце, сесії, рекомендації, повний журнал операцій | `mo history --json` |
| **Захист** | Чого Mole не має чіпати ніколи: правила кешів, власні шляхи, виключені задачі, теки пошуку проєктів | `~/.config/mole/*` |
| **Інструменти** | Touch ID для sudo, очищення метаданих на зовнішніх дисках, оновлення Mole, автодоповнення, Raycast / Alfred, MCP тільки на читання для AI-агентів | `mo touchid`, `mo clean --external`, `mo update` |
| **Безпека** *(заплановано)* | Перевірка на шкідливе ПЗ на вимогу: аудит автозапуску й LaunchAgents, перевірка підписів і нотаризації, локальні YARA-правила Apple XProtect, рушій ClamAV (встановлюється на запит). Кожна знахідка пояснена й ніколи не позначається автоматично; з карантину файл можна відновити | Security.framework, `yara`, `clamd` / `freshclam` |

## Як користуватися

1. **Відкрийте Nora.** Якщо Mole немає, Nora запропонує встановити його — без Термінала й без пароля адміністратора.
2. **Оберіть модуль** на панелі ліворуч (або <kbd>⌘1</kbd>…<kbd>⌘8</kbd>, або <kbd>⌘K</kbd> для палітри команд).
3. **Натисніть «Сканувати».** На цьому кроці нічого не видаляється: Nora запускає попередній перегляд Mole.
4. **Перегляньте список.** Зніміть позначку з того, що хочете залишити, або захистіть назавжди кнопкою зі щитом.
5. **Запустіть.** Nora покаже точну команду, попросить Touch ID лише для системних зон і покаже результат. «Переглянути лог» відкриває консоль із повним виводом Mole.

Пункт у меню-барі (<kbd>⌥⌘N</kbd>) показує живі показники; права кнопка відкриває швидкі дії.

## Безпека

- Nora ніколи не видаляє нічого сама: видалення буває лише після перегляду й явного підтвердження.
- Кеші й журнали (`mo clean`) та артефакти проєктів (`mo purge`) видаляються остаточно; Mole перевіряє кожен шлях ще раз перед видаленням. Програми за замовчуванням ідуть у Кошик.
- 13 типових захистів Mole (моделі Ollama, кеші Gradle і JetBrains, браузери Playwright, iCloud…) та його обов'язкові правила зберігаються, коли Nora змінює whitelist.
- Права адміністратора запитуються через системне вікно або Touch ID, використовуються в межах однієї сесії з командою Mole і ніколи не зберігаються.
- Без телеметрії. Мережа використовується лише для перевірки оновлень (Nora і Mole) та завантаження інсталятора Mole, і все це видно в консолі.

## Встановлення

> [!IMPORTANT]
> Застосунок ще не випущено. Коли вийде, завантажте `Nora.dmg` зі сторінки [Releases](https://github.com/Lexus2016/Nora/releases), відкрийте й перетягніть **Nora** у **Програми**.

- macOS 14 Sonoma або новіша, Apple silicon або Intel.
- [Mole](https://github.com/tw93/Mole) 1.55 або новіший — Nora встановить або оновить його сама.
- Рекомендовано надати повний доступ до диска, щоб сканувалися Пошта, Safari й частина кешів. Nora підкаже, як це зробити.

## Прототип

Затверджений інтерактивний прототип працює в будь-якому сучасному браузері; усі дані в ньому демонстраційні.

- Онлайн: **https://lexus2016.github.io/Nora/prototype/**
- Локально: `cd prototype && python3 -m http.server 8000` → http://localhost:8000

Перемикач **«Сценарії»** вгорі показує стани першого запуску, застарілого Mole, відсутнього повного доступу до диска й сесії адміністратора.
